# Complete Application Internationalization Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Complete Chinese and English localization for every platform-owned user-facing string while preserving user data, model output, logs, URLs, provider names, and browser engine identifiers.

**Architecture:** Keep `createTranslator` and `I18nProvider` as the public API, split locale dictionaries into focused message modules, and use `useI18n()` at rendering boundaries. Dynamic application messages use the translator at the event that creates them so confirmations, generated labels, and runtime feedback follow the active interface locale.

**Tech Stack:** React 19, TypeScript, Vitest, Testing Library, Vite, Electron.
